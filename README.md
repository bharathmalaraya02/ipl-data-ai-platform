# IPL Data & AI Platform

An end-to-end cloud-native Data Engineering, Data Science and AI platform
using IPL cricket data as the business domain.

## Architecture

Source → Ingestion → Data Lake → PySpark → BigQuery → Data Modeling
→ Data Quality → Orchestration → Analytics → ML → AI

## Technology Stack

- Python
- SQL
- PySpark
- Google Cloud Storage
- BigQuery
- dbt / Dataform
- Airflow / Cloud Composer
- Docker
- GitHub Actions
- Machine Learning
- Generative AI
